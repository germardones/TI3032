4. Iteración de Subdocumentos con PyMongo

Hasta ahora hemos ejecutado las consultas desde la shell de MongoDB. En la práctica, las aplicaciones acceden a la base de datos desde código. PyMongo es el driver oficial de MongoDB para Python: traduce dictionaries de Python a documentos BSON y expone la misma API de consultas que conoces — find(), find_one(), aggregate() — pero devolviendo objetos Python que puedes iterar, transformar y procesar con toda la potencia del lenguaje.

Instalación y Conexión

PyMongo se instala con pip. La conexión se establece a través de MongoClient, que acepta una URI de conexión estándar.

# Instalar PyMongo
pip install pymongo
from pymongo import MongoClient

# Conexión local (puerto por defecto 27017)
client = MongoClient("mongodb://localhost:27017/")

# Acceder a la base de datos y la colección
db         = client["tienda"]
pedidos    = db["pedidos"]
productos  = db["productos"]

Buena práctica: Usa un context manager o cierra el cliente explícitamente con client.close() al finalizar. En aplicaciones web o scripts de larga duración, reutiliza una sola instancia de MongoClient — crearla es costoso y los clientes gestionan un pool de conexiones internamente.

Iteración Básica de Resultados

find() en PyMongo retorna un Cursor, que es un iterador perezoso: no descarga todos los documentos de golpe, sino que los va trayendo del servidor a medida que los solicitas. Puedes recorrerlo con un for, convertirlo a lista con list(), o usar find_one() para obtener solo el primer resultado.

# Iterar todos los pedidos (cursor perezoso)
for pedido in pedidos.find():
    print(pedido["numero"], pedido["estado"])

# Obtener solo el primero
primero = pedidos.find_one({ "estado": "enviado" })
print(primero["numero"])  # → "ORD-2026-001"

# Convertir a lista (carga todos en memoria)
todos = list(pedidos.find())
print(len(todos))  # → 2

Acceso a Subdocumentos: Notación de Punto y Diccionarios

PyMongo devuelve cada documento MongoDB como un diccionario de Python. Los subdocumentos anidados son diccionarios dentro de diccionarios. Puedes acceder a sus campos con la sintaxis estándar de Python doc["clave"]["subclave"]. En los filtros de consulta, la dot notation sigue siendo un string entre comillas, exactamente igual que en la shell.

# Filtrar por campo de subdocumento (dot notation en el filtro)
cursor = pedidos.find({ "cliente.region": "Metropolitana" })

for doc in cursor:
    # Acceso al subdocumento como diccionario Python
    cliente = doc["cliente"]
    print(f"Pedido {doc['numero']} — Cliente: {cliente['nombre']} ({cliente['tipo']})")

Acceso Seguro con .get()

Si un campo puede estar ausente en algunos documentos, usar doc["campo"] lanzará un KeyError. El método .get() devuelve un valor por defecto (por defecto None) si la clave no existe — lo que hace la iteración más robusta.

for doc in pedidos.find():
    cliente = doc.get("cliente", {})
    nombre  = cliente.get("nombre", "Sin nombre")
    region  = cliente.get("region", "Sin región")
    print(f"{nombre} — {region}")

Iteración de Arreglos de Subdocumentos

Los arreglos de subdocumentos (como items) se representan en Python como listas de diccionarios. Puedes iterar sobre ellas con un bucle for anidado, aplicar comprensiones de lista o filtrarlas con filter().

# Recorrer todos los pedidos e imprimir sus items
for pedido in pedidos.find():
    print(f"\nPedido {pedido['numero']}:")
    for item in pedido.get("items", []):
        subtotal = item["cantidad"] * item["precio"]
        print(f"  · {item['producto']:25s} x{item['cantidad']}  → ${subtotal:>10,.0f}")

"""
Salida esperada:
Pedido ORD-2026-001:
  · Teclado Mecánico          x1  →     $85,000
  · Mouse Inalámbrico         x2  →     $40,900

Pedido ORD-2026-002:
  · Monitor 24"               x1  →    $320,000
"""

Filtros con $elemMatch desde PyMongo

Los operadores de MongoDB como $elemMatch, $gte, $all se expresan en PyMongo como strings dentro de diccionarios Python. La sintaxis es idéntica al JSON de la shell, simplemente usando comillas para las claves.

# Pedidos con al menos un item cuyo precio sea >= 50.000 Y cantidad >= 2
cursor = pedidos.find({
    "items": {
        "$elemMatch": {
            "precio":   { "$gte": 50000 },
            "cantidad": { "$gte": 2 }
        }
    }
})

for doc in cursor:
    print(doc["numero"])  # No retorna nada: ningún item tiene precio >= 50k Y cantidad >= 2

# Pedidos con al menos un item de precio > 80.000 (dot notation sobre arreglo)
cursor = pedidos.find({ "items.precio": { "$gt": 80000 } })
for doc in cursor:
    print(doc["numero"])  # → ORD-2026-001 y ORD-2026-002

Proyección desde PyMongo

El segundo argumento de find() es el diccionario de proyección, equivalente al segundo parámetro de find() en la shell. Sirve para traer solo los campos necesarios y reducir el volumen de datos transferidos.

# Traer solo numero, cliente.nombre e items (sin _id)
cursor = pedidos.find(
    { "estado": "enviado" },
    {
        "numero":         1,
        "cliente.nombre": 1,
        "items":          1,
        "_id":           0
    }
)

for doc in cursor:
    print(doc)

"""
{
  'numero': 'ORD-2026-001',
  'cliente': {'nombre': 'Valentina Ríos'},

}

Caso Práctico: Resumen de Pedidos con Cálculo de Totales

Un ejemplo completo que combina filtrado en subdocumentos, iteración de arreglos y procesamiento con Python para generar un resumen ejecutivo por pedido.

import re
from pymongo import MongoClient

client  = MongoClient("mongodb://localhost:27017/")
pedidos = client["tienda"]["pedidos"]

def resumen_por_region(region: str) -> None:
    filtro = {
        "cliente.region": { "$regex": region, "$options": "i" },
        "estado":          { "$ne": "cancelado" }
    }

    print(f"\n{'='*50}")
    print(f" Región: {region}")
    print(f"{'='*50}")

    total_general = 0
    for pedido in pedidos.find(filtro):
        nombre  = pedido["cliente"]["nombre"]
        items   = pedido.get("items", [])

        # Calcular total del pedido iterando el arreglo de subdocumentos
        total   = sum(i["precio"] * i["cantidad"] for i in items)
        n_items = len(items)

        print(f"\n  {pedido['numero']} — {nombre}")
        print(f"  Estado:  {pedido['estado']}")
        print(f"  Items:   {n_items}")
        print(f"  Total:   ${total:,.0f}")

        total_general += total

    print(f"\n  TOTAL REGIÓN: ${total_general:,.0f}")

resumen_por_region("Metropolitana")
client.close()

Uso de sort(), limit() y skip()

El cursor de PyMongo admite encadenamiento de métodos para ordenar, limitar y paginar resultados. Los campos de subdocumentos se ordenan igual que en la shell.

# Los 3 pedidos más caros (por precio del primer item)
cursor = (
    pedidos
    .find({ "estado": "enviado" })
    .sort("items.0.precio", -1)  # -1 = descendente
    .limit(3)
)

# Paginación: página 2, 10 resultados por página
pagina   = 2
por_pag  = 10
cursor   = pedidos.find().skip((pagina - 1) * por_pag).limit(por_pag)

Aggregation Pipeline desde Python

Para análisis más complejos sobre subdocumentos y arreglos, el aggregation pipeline es la herramienta correcta. En PyMongo se pasa como una lista de diccionarios al método aggregate().

# Sumar el total de ventas por región
pipeline = [
    { "$unwind": "$items" },
    {
        "$group": {
            "_id":    "$cliente.region",
            "total": {
                "$sum": {
                    "$multiply": ["$items.precio", "$items.cantidad"]
                }
            }
        }
    },
    { "$sort": { "total": -1 } }
]

for r in pedidos.aggregate(pipeline):
    print(f"{r['_id']:20s}  ${r['total']:>12,.0f}")

"""
Valparaíso            $   320,000
Metropolitana         $   125,900
"""
