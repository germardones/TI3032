4. API, JSON, Async/Await, Fetch y Axios

Las aplicaciones React rara vez trabajan solas — consumen datos de APIs REST mediante solicitudes HTTP. Para manejar estas operaciones asíncronas de forma legible, JavaScript provee async/await. Los datos se intercambian en formato JSON, y las herramientas más usadas son la API nativa fetch y la librería Axios.

JSON: El Formato Universal

JSON (JavaScript Object Notation) es el formato estándar para intercambiar datos entre frontend y backend. Es texto estructurado que cualquier lenguaje puede parsear.

// Objeto JavaScript → JSON string
const usuario = { nombre: "Ana", edad: 28, activo: true };
const json  = JSON.stringify(usuario);
// '{"nombre":"Ana","edad":28,"activo":true}'

// JSON string → Objeto JavaScript
const obj = JSON.parse(json);
console.log(obj.nombre); // "Ana"

Async/Await

async/await es syntactic sugar sobre las Promises. Permite escribir código asíncrono con la misma estructura lineal del código síncrono, evitando el "callback hell".

Con Promises encadenadas:

fetch('/api/usuarios')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

Con async/await:

async function obtenerUsuarios() {
  try {
    const res  = await fetch('/api/usuarios');
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}

Fetch API en React con useEffect

El patrón estándar para cargar datos al montar un componente combina useEffect con async/await.

import { useState, useEffect } from 'react';

function ListaUsuarios() {
  const [usuarios,  setUsuarios]  = useState([]);
  const [cargando,  setCargando]  = useState(true);
  const [error,     setError]     = useState(null);

  useEffect(() => {
    async function cargar() {
      try {
        const res  = await fetch('https://jsonplaceholder.typicode.com/users');
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        setUsuarios(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setCargando(false);
      }
    }
    cargar();
  }, []);  // [] = solo al montar

  if (cargando) return <p>Cargando...</p>;
  if (error)    return <p>Error: {error}</p>;

  return (
    <ul>
      {usuarios.map(u => <li key={u.id}>{u.name} — {u.email}</li>)}
    </ul>
  );
}

Axios: Alternativa más Robusta

Axios es una librería HTTP que simplifica las peticiones, maneja automáticamente la serialización JSON y tiene mejor gestión de errores que el fetch nativo.

# Instalación
npm install axios
import axios from 'axios';
import { useState, useEffect } from 'react';

// Instancia reutilizable con configuración base
const api = axios.create({
  baseURL: 'https://mi-backend.com/api',
  timeout: 5000,
  headers: { 'Authorization': `Bearer ${localStorage.getItem('token')}` }
});

// GET con Axios
async function obtenerProductos() {
  const { data } = await api.get('/productos');
  return data;
}

// POST con Axios
async function crearProducto(producto) {
  const { data } = await api.post('/productos', producto);
  return data;
}

Fetch vs. Axios

Característica fetch Axios
Instalación requerida No (nativo) Sí (npm install axios)
Parseo automático de JSON No (requiere .json()) Sí
Errores HTTP (4xx, 5xx) No lanza error automáticamente Lanza error automáticamente
Interceptores / baseURL Manual Integrado

Recomendación práctica: Para proyectos simples, fetch es suficiente. Para aplicaciones con autenticación, múltiples endpoints o necesidad de interceptores, Axios reduce considerablemente el código repetitivo.
