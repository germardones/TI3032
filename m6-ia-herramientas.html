5. Herramientas de IA en Desarrollo con React

El ecosistema de desarrollo moderno incorpora herramientas de inteligencia artificial que aceleran la escritura de código, detectan errores antes de llegar a producción y mejoran la calidad del software. Las dos herramientas más relevantes para proyectos React son GitHub Copilot y SonarQube.

GitHub Copilot

GitHub Copilot es un asistente de codificación con IA que sugiere líneas y funciones completas mientras escribes. Está integrado en VS Code, JetBrains y otros IDEs. Está entrenado en código público de GitHub y usa modelos de lenguaje para predecir el código más probable dado el contexto.

Casos de uso en React

// 1. Escribir el nombre de la función y Copilot sugiere la implementación
function useDebounce(valor, delay) {
  const [valorDebounced, setValorDebounced] = useState(valor);

  useEffect(() => {
    const timer = setTimeout(() => setValorDebounced(valor), delay);
    return () => clearTimeout(timer);
  }, [valor, delay]);

  return valorDebounced;
}

// Componente que muestra una tabla paginada de usuarios con búsqueda por nombre
function TablaUsuarios({ usuarios }) {

}

Buenas prácticas con Copilot

Hacer Evitar
Revisar cada sugerencia antes de aceptarla Aceptar código sin entenderlo
Usar Copilot para tareas repetitivas (boilerplate) Delegar arquitectura o decisiones de diseño
Verificar que las dependencias sugeridas existan Confiar ciegamente en imports de módulos inventados
Usar contextos específicos (comentarios claros) Esperar sugerencias correctas sin contexto

SonarQube

SonarQube es una plataforma de análisis estático de código que detecta bugs, vulnerabilidades de seguridad, code smells y mide la cobertura de tests. Se integra con pipelines CI/CD para evitar que código problemático llegue a producción.

Problemas que detecta SonarQube en React

// ❌ SonarQube detecta: Posible XSS con dangerouslySetInnerHTML
function ContenidoInseguro({ html }) {
  return <div dangerouslySetInnerHTML={{ __html: html }} />;
  // Regla: react/no-danger — riesgo de XSS si `html` viene de usuario
}

// ✅ Alternativa segura: sanitizar primero
import DOMPurify from 'dompurify';

function ContenidoSeguro({ html }) {
  const htmlLimpio = DOMPurify.sanitize(html);
  return <div dangerouslySetInnerHTML={{ __html: htmlLimpio }} />;
}
// ❌ SonarQube detecta: useEffect sin cleanup puede causar memory leak
useEffect(() => {
  const id = setInterval(() => console.log('tick'), 1000);
  // Falta el return con clearInterval
}, []);

// ✅ Con cleanup correcto
useEffect(() => {
  const id = setInterval(() => console.log('tick'), 1000);
  return () => clearInterval(id);
}, []);

Métricas clave de SonarQube

Métrica Descripción
Bugs Errores de lógica que causarán fallos en runtime.
Vulnerabilidades Puntos de entrada para ataques (XSS, inyección, etc.).
Code Smells Código que funciona pero es difícil de mantener o entender.
Cobertura Porcentaje del código cubierto por pruebas automatizadas.
Deuda técnica Tiempo estimado para corregir todos los problemas detectados.

Integración en el flujo de trabajo

# sonar-project.properties — configuración básica
sonar.projectKey=mi-app-react
sonar.projectName=Mi App React
sonar.sources=src
sonar.exclusions=**/node_modules/**,**/*.test.js
sonar.javascript.lcov.reportPaths=coverage/lcov.info
# Ejecutar análisis (requiere SonarQube Server o SonarCloud)
npx sonar-scanner

Flujo recomendado: Copilot acelera la escritura de código → ESLint / Prettier mantiene el estilo → SonarQube detecta vulnerabilidades → los tests verifican el comportamiento. Las herramientas de IA no reemplazan las pruebas; las complementan.
