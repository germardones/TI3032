1. Introducción a React

React es una biblioteca JavaScript de código abierto desarrollada por Meta (Facebook) desde 2013. Su propósito es construir interfaces de usuario interactivas a partir de piezas reutilizables llamadas componentes. A diferencia de frameworks MVC tradicionales, React se centra únicamente en la capa de vista (la "V" del modelo MVC), delegando enrutamiento, estado global y llamadas a APIs a librerías complementarias.

¿Por qué React?

Antes de React — manipulación directa del DOM:

// Actualizar el DOM manualmente es propenso a errores
document.getElementById('contador').innerText = 0;
document.getElementById('btn')
  .addEventListener('click', () => {
    let n = +document.getElementById('contador').innerText;
    document.getElementById('contador').innerText = n + 1;
  });

Con React — declarativo y reactivo:

import { useState } from 'react';

function Contador() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>{n}</button>;
}

Conceptos Fundamentales

Concepto Descripción
Virtual DOM React mantiene una copia liviana del DOM en memoria. Cuando el estado cambia, calcula las diferencias (diffing) y solo actualiza lo que realmente cambió en el DOM real.
JSX Sintaxis que combina JavaScript con marcado similar a HTML. No es obligatorio pero sí la convención estándar. Babel lo transpila a React.createElement() bajo el capó.
Componentes Funciones (o clases) que reciben datos (props) y retornan JSX. Son la unidad de construcción de toda UI en React.
Estado (State) Datos internos de un componente que, al cambiar, provocan un re-renderizado. Se gestiona con el hook useState.
Props Datos que el componente padre pasa al hijo. Son de solo lectura desde el componente hijo — el flujo es siempre de padre a hijo (one-way data flow).

Crear un Proyecto con Vite

La forma recomendada en 2024–2025 es usar Vite como bundler y servidor de desarrollo. Es significativamente más rápido que Create React App (CRA), que ya no recibe mantenimiento activo.

# Crear proyecto React con Vite
npm create vite@latest mi-app -- --template react
cd mi-app
npm install
npm run dev

La estructura generada es:

mi-app/
├── public/          # archivos estáticos
├── src/
│   ├── assets/      # imágenes, íconos
│   ├── App.jsx      # componente raíz
│   └── main.jsx     # punto de entrada
├── index.html
├── vite.config.js
└── package.json

El Primer Componente

Un componente funcional es simplemente una función de JavaScript que retorna JSX. Por convención, su nombre comienza con mayúscula.

// src/components/Saludo.jsx
function Saludo({ nombre }) {
  return (
    <div>
      <h2>Hola, {nombre}!</h2>
      <p>Bienvenido a React.</p>
    </div>
  );
}

export default Saludo;
// src/App.jsx — uso del componente
import Saludo from './components/Saludo';

function App() {
  return <Saludo nombre="Estudiante" />;
}

export default App;

React vs. Otros Frameworks

Característica React Vue 3 Angular
Tipo Biblioteca Framework progresivo Framework completo
Lenguaje base JSX (JS + HTML) SFC (.vue) TypeScript
Curva de aprendizaje Media Baja Alta
Ecosistema Muy grande Grande Grande

Dato clave: React es la biblioteca frontend más demandada en el mercado laboral. Según el State of JS 2024, más del 80% de los desarrolladores que la han usado continuarían usándola. Su dominio del ecosistema se traduce directamente en oportunidades laborales.
