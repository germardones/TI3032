3. Local Storage

Local Storage es una API del navegador que permite guardar datos de forma persistente en el dispositivo del usuario, incluso después de cerrar la pestaña o el navegador. A diferencia de las variables de estado de React (que se pierden al recargar), Local Storage sobrevive entre sesiones.

API Nativa del Navegador

Local Storage almacena pares clave–valor como strings. Para guardar objetos complejos, se usa JSON.stringify() al escribir y JSON.parse() al leer.

// Escribir
localStorage.setItem('usuario', 'Ana');
localStorage.setItem('preferencias', JSON.stringify({ tema: 'oscuro', idioma: 'es' }));

// Leer
const nombre = localStorage.getItem('usuario');                          // 'Ana'
const prefs  = JSON.parse(localStorage.getItem('preferencias'));     // { tema: 'oscuro', ... }

// Eliminar una clave
localStorage.removeItem('usuario');

// Limpiar todo
localStorage.clear();

Integración con React: Hook Personalizado

El patrón más limpio es encapsular la lógica de Local Storage en un hook personalizado que sincroniza el estado de React con el almacenamiento del navegador automáticamente.

// src/hooks/useLocalStorage.js
import { useState } from 'react';

function useLocalStorage(clave, valorInicial) {
  const [valor, setValor] = useState(() => {
    try {
      const guardado = localStorage.getItem(clave);
      return guardado !== null ? JSON.parse(guardado) : valorInicial;
    } catch {
      return valorInicial;
    }
  });

  function guardar(nuevoValor) {
    try {
      setValor(nuevoValor);
      localStorage.setItem(clave, JSON.stringify(nuevoValor));
    } catch (err) {
      console.error('Error al guardar en localStorage:', err);
    }
  }

  return [valor, guardar];
}

export default useLocalStorage;
// Uso del hook en cualquier componente
import useLocalStorage from './hooks/useLocalStorage';

function SelectorTema() {
  const [tema, setTema] = useLocalStorage('tema', 'claro');

  return (
    <button onClick={() => setTema(tema === 'claro' ? 'oscuro' : 'claro')}>
      Tema actual: {tema}
    </button>
  );
}

Caso Práctico: Lista de Tareas Persistente

import useLocalStorage from './hooks/useLocalStorage';

function TodoApp() {
  const [tareas,  setTareas]  = useLocalStorage('tareas', []);
  const [nuevaTarea, setNuevaTarea] = useState('');

  function agregar() {
    if (!nuevaTarea.trim()) return;
    setTareas([...tareas, { id: Date.now(), texto: nuevaTarea, hecha: false }]);
    setNuevaTarea('');
  }

  function toggleHecha(id) {
    setTareas(tareas.map(t => t.id === id ? { ...t, hecha: !t.hecha } : t));
  }

  return (
    <div>
      <input value={nuevaTarea} onChange={e => setNuevaTarea(e.target.value)} />
      <button onClick={agregar}>Agregar</button>
      <ul>
        {tareas.map(t => (
          <li key={t.id}
              onClick={() => toggleHecha(t.id)}
              style={{ textDecoration: t.hecha ? 'line-through' : 'none' }}>
            {t.texto}
          </li>
        ))}
      </ul>
    </div>
  );
}

Local Storage vs. Otras Opciones de Almacenamiento

Mecanismo Persistencia Capacidad Uso típico
useState Solo en memoria Ilimitada (RAM) Estado temporal de la UI
Local Storage Permanente (sin expiración) ~5 MB Preferencias, tokens, caché
Session Storage Solo mientras dure la pestaña ~5 MB Datos de la sesión activa
IndexedDB Permanente Cientos de MB Datos complejos / offline

Advertencia de seguridad: Nunca almacenes contraseñas, tokens de acceso de alta sensibilidad ni datos personales críticos en Local Storage. Es accesible a cualquier script JavaScript en la página, lo que lo hace vulnerable a ataques XSS.
